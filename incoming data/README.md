# Incoming survey data

Filtered copy of the project's `Incoming Data` folder, committed for reference on 07 Nov 2026.

## Included
- WPR files in PDF format only.
- Shapefile components: `.shp`, `.shx`, `.dbf`, `.prj`, `.cpg`, `.qmd` and index/metadata sidecars.
- KML/KMZ files used by the dashboard.
- CSV/GPKG reference tables.

## Excluded
- Ortho imagery (TIFF/WebP/PNG).
- WPR DOCX files. Shahjahanpur and Saharanpur WPRs are DOCX-only in the source and are therefore not included.
- Map images, photo archives and ZIP/RAR archives.
- `Saharanpur/Photos KML/Saharanpur_photos 1.kmz` (86 MB photo archive).
